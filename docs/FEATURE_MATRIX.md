# Feature comparison and v1 triage

As of 2026-09-25. Categories: **BOTH**, **K4 ONLY**, **DROPPY ONLY**, **SIMILAR BUT DIFFERENT**, **UNCERTAIN**. k4 cells are source findings, not live QA; Droppy cells are from its [handbook](https://getdroppy.app/docs) and [Droplets list](https://getdroppy.app/docs/droplets). “Better” judges the documented workflow, not visual quality observed side by side. The architecture and v1 direction are approved, but implementation still requires approval. `Later` preserves the idea; `Reject` is a product-fit decision. Support tiers define release validation, not deletion permission. “V1 preserve” means inherited capability stays available without major redesign. Dependency terms are expanded in [PORTABILITY.md](PORTABILITY.md); see [v1 experience](V1_EXPERIENCE.md).
