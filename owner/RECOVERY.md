# Quick recovery

1. If the test freezes, stop clicking it. Your usual desktop should still be available.
2. Use the **Stop CP-NN** action in the labelled test terminal or launcher Codex provided.
   It must stop only the test copy.
3. Use **Restore previous** if you want the last working test version and its matching settings.
4. If those actions fail, tell Codex **NEEDS HELP — Stop/Restore failed**, with the checkpoint/run.
   Take a photo if a screenshot is impossible. Keep the terminal open for the error message.

Codex must provide and rehearse these actions before asking you to test. There are no launch/stop
actions yet: CP-00 creates them after your authorization. If you have not received them, do not start.

Do not run the installer, kill every Quickshell process, stop your notification app or overwrite your
personal settings. Codex will identify the exact test process and restore its own backup. Personal
settings are restored only after you approve the exact backup and files. You should never need to
repair QML code or your desktop configuration to recover from a checkpoint test.
