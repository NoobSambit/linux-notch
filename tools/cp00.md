# CP-00 isolated runtime tooling

Engineering tooling only; current readiness is in `docs/workflow/progress.json`.
No owner Start/Stop/Restore action is ready until its actual rehearsal is recorded.

`cp00.py` uses installed bubblewrap. The host shell's HOME is never reassigned.
Each sandbox has a synthetic `/home/cp00`, private network/PID/IPC/mount namespaces,
private `/tmp` and a restricted `/dev`. Only render nodes are shared for rendering;
no DRM card, input, sound or camera node is exposed. The compositor receives a
single parent Wayland socket; the independent app sandbox receives no parent socket,
host home, host runtime, system bus, portal or audio connection. The only session bus
is created inside the app sandbox. No packages, session services or config are changed.

Prepare the pinned source export without `.git` or worktree pointers:

```sh
mkdir -p scratch/cp00/lab/original
git archive ff520e33e136bbce11b7100c69888dedf42f7273 | tar -x -C scratch/cp00/lab/original
python3 tools/cp00.py prepare
python3 tools/cp00.py server-start
```

Then prove app boundaries before starting the nested compositor. `exec` runs commands
in the private app namespace and bus; its arguments are passed as an array, not a shell
string. The server is local to the mode-0700 disposable lab. All subprocesses inherit
only the allowlisted synthetic environment. It does not launch k4 automatically.

```sh
python3 tools/cp00.py exec -- python3 -c 'import os; print(dict(os.environ))'
python3 tools/cp00.py compositor-start
python3 tools/cp00.py exec -- hyprctl -j monitors
python3 tools/cp00.py compositor-stop
python3 tools/cp00.py server-stop
```

Stop pins the exact saved payload process with a pidfd after checking PID, start ticks,
executable, arguments, namespace and lab inode. The command-server payload exit tears down
its private session/PID namespace; the compositor payload exit closes only the nested desktop. Refused identities are never replaced
with a global kill. Revalidate handles after resume. Later recovery tooling will add
full Quickshell ID/config/start-time checks and dummy-store backup/restore rehearsals.
